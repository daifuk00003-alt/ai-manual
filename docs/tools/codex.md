# Codex

OpenAIが提供するAIコーディングエージェント／ツール群。ChatGPTのコード生成能力を、実際の開発環境で自律的に作業できる形に拡張したもの。

## 1. 概要

- **何ができるツールか**: [Claude（Code）](claude-code.md)と同様、コードの生成・修正・実行を自律的に行えるコーディングエージェント。指示を受けて、必要なファイルを読み書きし、コマンドを実行しながらタスクを完了させる。
- **提供形態**: ターミナルで動く[CLI](../glossary/index.md#cli-command-line-interface)版に加えて、IDE拡張、そしてクラウド上のサンドボックス環境でタスクを実行する形態など、複数の使い方が用意されている。クラウド実行では、手元のパソコンのリソースを使わずに、バックグラウンドでタスクを進められる点が特徴。

## 2. 仕組み

- **ベースとなるモデル**: OpenAIのGPTシリーズのうち、コーディング用途に強いモデルを土台にしている。
- **エージェント的な動作**: 与えられたタスクを分解し、ファイル操作・コマンド実行といった必要な手段を自分で選んで呼び出しながら進める、[エージェント](../glossary/index.md#ai)としての動作は他のコーディングエージェントと共通する仕組み。
- **サンドボックス実行**: コマンドの実行を、隔離された安全な環境（サンドボックス）内で行うことを前提に設計されており、意図しない形でシステム全体に影響が及ぶリスクを抑える工夫がされている。

## 3. 基本的な使い方

1. **セットアップ〜起動**: CLIをインストールし、対象のプロジェクトフォルダで起動する。あるいはIDE拡張やクラウド環境から利用を開始する。
2. **指示を出す**: 「〇〇の機能を実装して」「このテストが失敗する原因を直して」のように、達成したいことを伝える。
3. **結果を確認する**: 生成・修正されたコードやコマンドの実行結果を確認し、必要であれば追加の指示を出して調整する。

## 4. 具体例

- 新しい機能の実装を一通り任せ、生成されたコードをレビューする。
- 失敗しているテストの原因調査から修正までを依頼する。
- 定型的なコード変換・リファクタリング作業をまとめて依頼する。

## 5. 注意点・限界

- **実行環境・権限**: どの操作をどこまで自動で行わせるか（確認を挟むか、サンドボックス内で完結させるか等）を理解した上で使う必要がある。
- **料金・利用量の考え方**: 他のAIツールと同様、やり取りする文章量や実行時間に応じて利用量がカウントされる仕組みが一般的。

## 6. 他ツールとの比較

| 観点 | Claude（Code） | Codex |
|---|---|---|
| 強み | 長い[コンテキストウィンドウ](../glossary/index.md#context-window)を活かした大規模なリポジトリの読解・横断的な修正、サブエージェントやスキルによる作業の整理のしやすさ | OpenAIのエコシステム（ChatGPT等）との親和性、クラウド実行によるバックグラウンドでのタスク処理のしやすさ、サンドボックス実行を前提とした安全な自動実行 |
| 弱み | 画像生成等コーディング以外の周辺タスクは他ツールとの併用が必要 | エコシステムやツール構成が変化中で、情報が流動的な部分がある |
