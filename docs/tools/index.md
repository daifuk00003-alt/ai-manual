# ツール別基礎編について

このセクションでは、対象とする7つのツール（Claudeは3モードに分けているため実質8ページ）について、それぞれ同じテンプレートで解説します。

## ページの共通テンプレート

各ツールのページは、以下の6項目で統一しています。

1. **概要** — 何ができるツールか
2. **仕組み** — 技術的な裏側の解説（わかりやすさ優先）
3. **基本的な使い方**
4. **具体例**
5. **注意点・限界**
6. **他ツールとの比較**（簡易比較表）
