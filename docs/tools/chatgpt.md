# ChatGPT

OpenAIが提供する、対話型AIチャットサービス。世界で最も広く使われているAIチャットツールで、多くの人にとって「生成AI」に初めて触れるきっかけになったツールでもある。

## 1. 概要

ChatGPTは、文章の作成・要約・翻訳・アイデア出し・コード生成・画像生成・音声対話など、幅広いタスクを1つの対話画面でこなせる汎用AIチャットツール。

- **提供形態**: Webブラウザ版、モバイルアプリ（iOS / Android）、デスクトップアプリ、そして開発者向けのAPIが用意されている。
- **主なプラン**:
    - **Free**（無料）: 基本的なチャット機能を利用可能。利用回数や使えるモデルに制限がある。
    - **Plus**: 個人向けの有料プラン。利用上限が緩和され、上位モデルや画像生成、Deep Research（詳細調査）などの機能が使いやすくなる。
    - **Pro**: より高い利用上限と、最上位クラスのモデル・機能へのアクセスを提供する個人向けプラン。
    - **Team / Enterprise**: 組織・チーム向け。管理機能やセキュリティ面の強化、データの学習利用に関する扱いなどが個人プランと異なる。

用語集の[LLM](../glossary/index.md#llmlarge-language-model)についての説明も合わせて参照するとイメージがつかみやすい。

## 2. 仕組み

- **ベースとなるモデル**: 「GPT」シリーズと呼ばれる[LLM](../glossary/index.md#llmlarge-language-model)を土台にしている。世代が上がるごとに、文章の質・推論力・マルチモーダル対応（画像や音声の理解）が強化されてきた。用途や速度・コストのバランスに応じて複数のモデルから選べるようになっていることが多い。
- **会話の仕組み**: ユーザーが入力した[プロンプト](../glossary/index.md#prompt)を受け取り、これまでの会話（[コンテキストウィンドウ](../glossary/index.md#context-window)に収まる範囲）を踏まえて、次に続く文章を予測しながら応答を生成する。複雑な質問に対しては、内部で段階的に考える「[推論](../glossary/index.md#reasoning)」を行うモデルも選択できる。
- **メモリ機能**: 過去のやり取りの中から、ユーザーの好みや繰り返し出てくる情報を記憶し、以降の会話に活かす機能がある。会話ごとに完全にリセットされるわけではない点が、他のシンプルなチャットツールとの違いになりやすい。
- **カスタム指示**: 「常にこう振る舞ってほしい」という設定をあらかじめ登録できる。これは用語集の[システムプロンプト](../glossary/index.md#system-prompt)の考え方に近い。
- **GPTs（カスタムChatGPT）**: 特定の目的に特化した振る舞い・知識・連携ツールをあらかじめ設定した「専用ChatGPT」を、自分で作成したり、他の人が公開したものを使ったりできる仕組み。

## 3. 基本的な使い方

1. **アカウント作成**: メールアドレスまたはGoogle/Microsoftアカウント等でサインアップし、チャット画面から利用を開始する。
2. **プロンプトを入力する**: 画面下部の入力欄に指示や質問を入力する。目的・条件・出力形式（箇条書きで、100字以内で、等）を具体的に書くほど、意図に近い応答が得やすい。
3. **ファイル・画像を添付する**: PDFや画像、表計算ファイルなどを会話にアップロードし、その内容について質問したり、要約させたりできる。
4. **会話（スレッド）を管理する**: やり取りは「チャット」単位で保存され、後から見返したり、続きから再開したりできる。話題が変わるときは新しいチャットを開始すると、余計な文脈を持ち越さずに済む。

## 4. 具体例

- 長い会議メモを渡して「要点を3つに絞って箇条書きで要約して」と依頼する。
- 書いた文章を貼り付けて「敬語のトーンで、誤字脱字と言い回しをチェックして」と添削を依頼する。
- コードのエラーメッセージを貼り付けて「原因と修正案を教えて」と相談する。
- 企画のアイデア出しの相手として、案を出しては壁打ちしてもらう。

## 5. 注意点・限界

- **ハルシネーション**: [用語集](../glossary/index.md#hallucination)でも触れている通り、誤った情報を自信を持って回答することがある。固有名詞・数値・出典などは鵜呑みにせず確認する。
- **最新情報への弱さ**: モデルは学習した時点までの情報しか基本的には持たない。ただし検索機能と連携させることで、ある程度は最新情報も扱えるようになっている。
- **データの取り扱い**: 入力した内容が、プランによってはモデルの学習に利用される場合がある（設定でオフにできることが多い）。機密情報や個人情報の入力には注意が必要。
- **利用規約**: 商用利用や生成物の取り扱いについて、規約上の制約があるため確認が必要な場面がある。

## 6. 他ツールとの比較

| 観点 | ChatGPT | Gemini | Claude |
|---|---|---|---|
| 強み | 利用者数・エコシステムの大きさ、GPTsによる拡張性、画像生成やAdvanced Voiceなどマルチモーダル機能の幅広さ | Google検索・Workspaceとの連携による最新情報へのアクセスのしやすさ、動画も含めたマルチモーダル対応の強さ | 長文の読解・要約に強く、文章の質や指示追従性が高いとされる。ArtifactsやProjectsによる資料整理のしやすさ、コーディング用途（Claude Code）にも強い |
| 弱み | ハルシネーションや最新情報への弱さは他ツール共通の課題 | Googleサービスを使っていない人にとっては連携の恩恵が薄い | 画像生成機能を持たない（他ツール・サービスとの併用が必要）、無料プランの利用上限が厳しめ |
