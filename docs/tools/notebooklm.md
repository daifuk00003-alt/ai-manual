# NotebookLM

Googleが提供する、自分でアップロードした資料を情報源として、対話・要約・音声解説を生成できるAIノートツール。「持ち込んだ資料の範囲内で回答する」という設計思想が、汎用チャットAIとの一番の違い。

## 1. 概要

- **何ができるツールか**: PDFや文書、Webページ、動画・音声などをまとめて「ノートブック」に追加すると、その内容についてAIに質問したり、要点を要約させたり、資料同士を比較させたりできる。加えて、資料の内容を対話形式の音声コンテンツにまとめる「音声概要（Audio Overview）」機能が特徴的。
- **提供形態**: Webブラウザ版（notebooklm.google.com）で提供されている。

## 2. 仕組み

- **ソースに基づく回答**: NotebookLMは、[LLM](../glossary/index.md#llmlarge-language-model)が学習した一般知識だけに頼るのではなく、ユーザーが追加した資料（ソース）を情報源として優先的に参照し、その内容に基づいて回答する。用語集の[RAG](../glossary/index.md#ragretrieval-augmented-generation)（検索拡張生成）に近い考え方で、回答には参照元のどの部分から得た情報かを示す引用がつくことが多く、元の資料を辿って確認しやすい。
- **音声概要の生成**: アップロードした資料の内容をもとに、2人の話者が対話形式で解説するような音声コンテンツを自動生成できる。文章を読む代わりに「聞いて理解する」ことができる。

## 3. 基本的な使い方

1. **ノートブックを作成する**: 新しいノートブックを作り、そこにPDF・Googleドキュメント・Webページのリンク・音声/動画ファイルなどを資料として追加する。
2. **チャットで質問する**: 追加した資料の内容について、「この資料の要点を教えて」「AとBの違いは？」のように質問する。
3. **音声概要を生成する**: ボタン一つで、資料の内容をまとめた対話形式の音声を生成し、再生できる。

## 4. 具体例

- 論文や長い報告書をアップロードし、要点や重要な数値を素早く把握する。
- 複数の資料（例: 競合サービスの資料を複数）を追加し、共通点や違いを横断的に比較させる。
- 移動時間などに、資料の内容を音声概要として「ながら聞き」する。

## 5. 注意点・限界

- **対応ファイル形式・容量の制約**: 扱えるファイル形式やアップロードできる分量には上限があり、非常に大きな資料や特殊な形式のファイルは扱えないことがある。
- **情報源の範囲外には答えられない**: 汎用チャットAIと異なり、追加していない資料の内容や、資料に書かれていない一般知識については、基本的に回答の対象外（answerできない、または「情報がない」という扱いになる）。この制約自体が、ハルシネーションを抑える設計にもなっている。

## 6. 他ツールとの比較

| 観点 | NotebookLM | ChatGPT / Claude 等の汎用チャットAI |
|---|---|---|
| 強み | 持ち込んだ資料の範囲に回答を限定できるためハルシネーションが起きにくい、音声概要による「ながら学習」のしやすさ | 資料の有無にかかわらず幅広い話題に対応でき、文章作成やコーディングなど汎用的な作業にも使える |
| 弱み | 資料に書かれていないことには答えられない、雑談や汎用的な作業には不向き | アップロードした資料の内容に厳密に基づかせるには、プロンプトでの工夫が必要になりやすい |
